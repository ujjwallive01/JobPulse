# JobPulse

A job discovery dashboard built with React, Vite and Tailwind CSS.

## Features
- Search jobs by title
- Filter by category and job type
- Save jobs, kept after refresh using Local Storage
- Responsive layout

## Tech Stack
React, JavaScript (ES6+), Tailwind CSS, Vite, Local Storage API

## Run locally
npm install
npm run dev

Job data provided by [Remotive](https://remotive.com).
